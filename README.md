# AI-Powered DGA Threat Hunter & Automated Alert Engine

## Overview
The **AI-Powered DGA Threat Hunter** is a Python-based cybersecurity project designed to detect suspicious domain names that may be generated by malware. These domains are often used by attackers to establish Command and Control (C2) connections and communicate with infected systems.

The project uses Machine Learning to analyze domain name patterns, classify potentially malicious domains, and automatically send alerts to a Discord channel when a threat is detected. The goal is to make suspicious domain detection faster and help security teams respond to potential threats more efficiently.

## Features

- **Smart Domain Analysis:** Uses character-level N-gram analysis with `TfidfVectorizer` to identify patterns in domain names. It examines 2-character and 3-character sequences to distinguish common domain patterns from suspicious ones.

- **Machine Learning-Based Detection:** Trains a `MultinomialNB` (Multinomial Naive Bayes) model to classify domains into two categories: Safe Human (0) and Malicious DGA (1).

- **Automated Security Alerts:** Integrates with the Discord Webhook API to send HTTP POST notifications whenever a domain is flagged as potentially malicious.

- **Lightweight and Efficient:** Built with Python and popular machine learning libraries, making it easy to set up, test, and extend.

## Tech Stack

- **Language:** Python 3.x
- **Machine Learning:** scikit-learn
- **HTTP Requests:** requests
- **Alert Integration:** Discord Webhooks

## Installation & Setup

### 1. Clone the Repository

Replace `YOUR_GITHUB_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/AI-DGA-Threat-Hunter.git
cd AI-DGA-Threat-Hunter
```

### 2. Install Dependencies

Install the required Python libraries:

```bash
pip install scikit-learn requests
```

### 3. Configure Discord Alerts

Create a Discord webhook for your preferred channel and configure the project to use its webhook URL. Keep the webhook URL private and store it in an environment variable rather than hardcoding it into your source code.

### 4. Run the Project

Run the main Python script to start analyzing domain names and generating alerts for domains classified as potentially malicious.

*Note: The exact command depends on the entry-point filename used in your repository.*

## Why This Project?

Malware often uses Domain Generation Algorithms (DGAs) to generate domain names that help it maintain communication with Command and Control servers. Detecting these domains can be challenging because their names frequently change.

This project explores how Machine Learning can help identify suspicious domain patterns and automate the alerting process, reducing the need for manual investigation of every domain.
